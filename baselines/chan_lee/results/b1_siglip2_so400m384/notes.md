# chan_lee/b1_siglip2_so400m384

B1 zero-shot dual encoder: SigLIP2 so400m/16@384. 전체 후보 15,000장에 대한 코사인 유사도로 정렬했습니다.

## 관찰

- **score 0.427** [95% CI 0.418–0.435], R@1 0.315, NDCG@5 0.538
  - Public 0.466 / Private 0.421
  - 기준 문항 0.820 / 묶음 문항 0.383
- 난이도의 대부분은 **HN보다 묶음 구조**에서 나옵니다. 오답 top-1의 출처는 다음과 같습니다.

  | 출처 | 비율 |
  |---|---|
  | 같은 묶음의 다른 원본 | 44.8% |
  | 그 원본의 HN | 13.6% |
  | 자기 HN | 7.1% |
  | 기타 | 3.1% |

  - 자기 HN이 정답보다 점수가 높은 경우는 Private 문항의 23%입니다.
  - Public과 Private의 차이(0.045)가 작은 이유도 여기에 있습니다. Public 문항에도 같은 묶음의 형제 7장이 후보로 남아 있습니다.
- 1단계 Recall@K: @5 74.1%, @10 90.8%, **@20 98.4%**, @50 99.75%.
  - 1단계가 묶음(형제 8장과 그 HN)을 top-20 안에 거의 다 가져옵니다.
  - 그래서 K=20 재정렬로 상한이 거의 열립니다. **2단계 설계가 보상받는 구조**입니다.
- 시간(MPS, M4 Max, fp16, 캐시 미사용; 참고용)

  | 단계 | 시간 |
  |---|---|
  | 모델 로딩 | 66s(첫 로딩) |
  | 이미지 15,000장 인코딩 | 790s(19장/s, I/O 대기 0.1s) |
  | 텍스트 8,000개 인코딩 | 42s |
  | 검색 | 0.1s |
  | 합계 | 899s |

  - 피크 메모리는 6.2GB입니다.

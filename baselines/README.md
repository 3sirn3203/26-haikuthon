# baselines/

운영진 베이스라인 실험 폴더입니다. 운영진 1인당 폴더 1개이고, 이름 규칙은 `이름_성`(소문자, 영문)입니다.

## 규칙

- **본인 폴더 안에서만** 파일을 만들고 수정합니다. `stage*/`, `outputs_stage*/`, 루트 설정 파일은 읽기만 합니다.
- 커밋할 때는 본인 폴더 경로만 지정합니다: `git add baselines/<본인폴더>`. `git add -A`, `git add .`, `git add baselines/`는 쓰지 않습니다(다른 사람의 변경이 섞입니다).
- 커밋 메시지에는 `<본인폴더>:` 접두어를 붙입니다.
- 데이터, 모델 가중치, 임베딩 캐시, 대용량 출력물은 커밋하지 않습니다. 필요한 ignore 규칙은 본인 폴더의 `.gitignore`에 둡니다.
  - 루트 `.gitignore`의 `test*/` 규칙 때문에 `tests/` 폴더도 무시됩니다. 테스트를 커밋하려면 본인 `.gitignore`에 `!tests/`를 추가하세요.
- test 프롬프트 원문과 정답 매핑은 대회 기밀입니다. 리포트에 쓰는 오류 예시는 10개 이내로 제한합니다.

## 결과 형식

모든 실험은 [RESULTS_SCHEMA.md](RESULTS_SCHEMA.md)의 `results/<exp_id>/metrics.json` 스키마를 따릅니다. 나중에 11명의 결과를 한꺼번에 모아 분석합니다.

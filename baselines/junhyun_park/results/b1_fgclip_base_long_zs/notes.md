# b1_fgclip_base_long_zs

b1_fgclip_base_zs와 같은 모델·같은 zip 구조에서 텍스트만 긴 캡션 모드(max_length 248, walk_short_pos=False)로 바꾼 zero-shot.

## 결과
- test_full 0.4170 (R@1 0.3075, NDCG@5 0.5264). Public 0.4534 / Private 0.4118.
- 77토큰 모드(0.4155) 대비 +0.0015. 사실상 차이 없음(Public 동일, Private +0.0017). 긴 프롬프트의 뒷부분(시점·조명)이 잘리는 것은 이 데이터에서 점수에 거의 영향이 없다. 난이도의 원천이 개수·방향·속성 같은 앞부분 slot이라는 점과 맞는다.

## 시간 (Modal L4, 캐시 없음)
- 서버 측정 기준 92.57s: 이미지 15,000장 76.4s, 텍스트 10.9s(77토큰 모드의 3.1s보다 증가), 검색 0.7s. 피크 VRAM 2.44GB(77토큰 모드 1.0GB).
- 같은 모델의 77토큰 실행은 이미지 인코딩이 241.6s였다. 이미지 처리 코드는 동일하므로 원인은 모델이 아니라 실행 환경 차이로 보이며(첫 실행의 Volume 콜드 읽기 가능성), 확인 전까지 이미지 인코딩 시간은 실행마다 크게 달라질 수 있다.

# B2: 이미지 후보 그래프 확산

## 한눈에 보기

기존 차트에는 없는 **이미지 이웃 그래프 확산** 방식을 시험했습니다. SigLIP2로 질의와 후보 이미지의 기본 점수를 만든 다음, 시각적으로 가까운 후보 이미지끼리 연결한 그래프에서 점수를 두 번 전파합니다.

| 항목 | 설정 또는 측정값 |
|---|---|
| 전체 점수 | **0.41199** |
| R@1 / NDCG@5 | 0.30588 / 0.51810 |
| 모델 | SigLIP2 SO400M/16@384, WebLI 사전학습, zero-shot |
| 파라미터 | 약 1.136B |
| 평가 규모 | 8,000개 질의, 후보 이미지 15,000장 |
| 그래프 | 이미지당 가까운 후보 10개, 두 차례 확산 |
| 실행 시간 | **568.3초 (9분 28초)** |
| 장치 / 피크 VRAM | RTX 4060 Laptop, 8GB / 5.72GB |

이번 실행에서는 기준선보다 전체 점수가 낮았습니다. 그래프 확산을 새 방식으로 기록하되, 성능 향상으로 해석하지 않습니다.

## 방법

1. SigLIP2로 8,000개 프롬프트와 후보 이미지 15,000장의 임베딩을 만듭니다.
2. 프롬프트와 이미지 사이의 코사인 유사도 행렬 `S`를 계산합니다.
3. 이미지 임베딩만 사용해 후보 이미지마다 가까운 이미지 10장을 찾습니다. 각 연결의 가중치는 코사인 유사도에 온도 0.07의 softmax를 적용하고, 그래프를 대칭화한 뒤 행별로 정규화합니다.
4. 각 프롬프트의 점수를 이미지 그래프에서 두 번 전파합니다.

```text
F₀ = S
Fₜ₊₁ = 0.85 × S + 0.15 × (Fₜ × A)
```

`A`는 정규화된 이미지 이웃 그래프입니다. 각 질의는 독립적으로 전파되며, 다른 질의의 점수나 정답 레이블은 사용하지 않습니다. 학습이나 train hard negative도 사용하지 않았습니다. 후보 이미지 풀의 시각적 이웃을 활용하는 비지도 후처리입니다.

## 데이터와 모델 규모

- Test 질의는 원본 이미지 8,000장에 대응합니다.
- 후보 풀은 원본 8,000장과 hard negative 7,000장, 총 15,000장입니다.
- 그래프는 후보 이미지 15,000개 노드에서 시작하며, 대칭화 전 이웃 연결은 최대 150,000개입니다.
- 사용 모델은 약 1.136B 파라미터입니다. 내려받은 safetensors 파일은 4.54GB였고, 결과 JSON의 2.27GB는 파라미터 수로 계산한 fp16 크기 추정치입니다.
- 데이터와 프롬프트는 로컬에서만 처리했습니다.

## 결과

같은 모델과 test 전체 풀을 사용한 기존 zero-shot 기준선과 비교했습니다.

| 방식 | 점수 | R@1 | NDCG@5 |
|---|---:|---:|---:|
| SigLIP2 zero-shot 기준선 (B1) | 0.42618 | 0.31450 | 0.53786 |
| 이미지 그래프 확산 (B2) | 0.41199 | 0.30588 | 0.51810 |
| 차이 (B2 − B1) | **−0.01419** | −0.00863 | −0.01976 |

B2는 잠정 public 분할에서 0.47780, 나머지 분할에서 0.40259를 기록했습니다. 이 public/private 구분은 공식 ID 목록이 아니라 hard-negative 짝짓기로 만든 **잠정 분할**이므로 참고용으로만 봐야 합니다. 전체 점수 하락과 sibling 이미지 오답 비중을 보면, 현재 그래프 확산 설정이 유사한 후보에 점수를 퍼뜨려 이 데이터에서는 도움이 되지 않았을 가능성이 있습니다.

점수는 `(R@1 + NDCG@5) / 2`입니다. 전체 순위 평가는 8,000개 질의 각각에 대해 15,000개 후보를 사용했습니다.

## 소요 시간과 메모리

| 단계 | 측정 시간 |
|---|---:|
| 모델 로딩 | 47.7초 |
| 이미지 인코딩 15,000장 | 464.8초 |
| 프롬프트 인코딩 8,000개 | 26.7초 |
| 기본 유사도 검색 | 2.5초 |
| 그래프 구성 및 확산 | 22.2초 |
| 전체 평가 | **568.3초** |

측정은 RTX 4060 Laptop GPU에서 이미지 임베딩 캐시 없이 수행했습니다. 전체 시간은 모델 가중치를 로컬 캐시에 내려받은 뒤의 평가 시간이며, 최초 4.54GB 다운로드 시간은 포함하지 않습니다. 다른 GPU와의 시간 비교에는 그대로 사용할 수 없습니다.

## 재현

저장소 루트에서 다음 명령으로 실행합니다.

```powershell
$env:HF_HOME = Join-Path (Get-Location) 'baselines/taekyoung_kwon/.cache/huggingface'
$env:HF_HUB_CACHE = Join-Path $env:HF_HOME 'hub'
& 'baselines/taekyoung_kwon/.venv/Scripts/python.exe' -B `
  'baselines/taekyoung_kwon/scripts/run_graph_diffusion.py' `
  --config 'baselines/taekyoung_kwon/configs/exp/b2_image_graph_diffusion.yaml'
```

설정은 [b2_image_graph_diffusion.yaml](configs/exp/b2_image_graph_diffusion.yaml), 실행 코드는 [run_graph_diffusion.py](scripts/run_graph_diffusion.py), 상세 지표는 [metrics.json](results/b2_image_graph_diffusion/metrics.json)에 있습니다.

# 기존 제출 결과 정리

## 관찰

- ResNet18 + 양방향 GRU의 독립 문항 검색 방식이다. 재정렬 모델은 없다.
- 전체 8,000문항 CSV의 R@1은 0.0035, NDCG@5는 약 0.01100031, 최종 score는 약 0.00725015다. 올바른 이미지가 Top1인 문항은 28개, Top5에 든 문항은 145개다.
- 사용자 관찰 GPU 평가 시간은 약 4분이다. GPU 배정 대기는 제외했다. 이번 정리에서 GPU 재실행은 하지 않았다.
- 피크 VRAM과 세부 단계별 시간은 측정하지 않았다. 이 기록은 시간·메모리 비교용 완성 벤치마크가 아니다.

## 비교 시 주의

Public 분할은 첨부 저장소의 `GUIDE.md`에 적힌 잠정 기준을 사용했다. 같은 ZIP의 `RESULTS_SCHEMA.md`에는 기준 문항과 seeded 표본을 조합한 다른 잠정 분할이 있다. 공식 목록이 정해지기 전에는 분할별 점수를 동일 조건으로 볼 수 없다. 전체 점수 계산은 8,000문항을 모두 포함한다.

원본 유사도 행렬이 없어 비관적 동점 처리를 검증하지 못했다. CSV를 다시 실행한 공식 평가 결과가 아니라, 기존 랭킹을 정답 규칙과 대조해 계산한 값이다. test를 이용한 추가 모델 선택이나 학습은 수행하지 않았다.

## 출처와 미확인 사항

- 모델 ZIP과 CSV는 사용자가 함께 제공한 파일이다. 원본 제출 UUID와 로그로 동일 실행임을 확인하지 못했다.
- 모델 구조·설정·어휘 크기·FP32 dtype·파라미터 수·가중치 크기는 파일에서 확인했다. 모델 코드와 학습 코드 원본은 복사했고 서버 코드나 CI를 변경하지 않았다.
- 원본 실행 커밋과 실제 학습 하이퍼파라미터는 자료에 없다. `git_commit`은 `unknown`이다. 결과의 날짜는 정리 날짜이다.
- 학습 여부는 사용자 설명에 근거한다. 학습 HN 사용 여부는 기존 Colab 기본값인 false를 옮겼지만 실제 실행 메타데이터로 검증하지 못했다. 그 한계를 `training_provenance`에 표시했다.
- ImageNet 초기화는 기존 학습 코드의 기본값이다. 실제 가중치의 사전학습 이력을 파일만으로 확정하지 않았다.
- 해당 학습 코드는 문항 무작위 10%를 검증으로 분리한다. 묶음 단위 분할이 아니어서 참조 검증 결과와 직접 비교할 수 없다.

원본 예측, 프롬프트, 정답 목록, 이미지, 가중치와 캐시는 이 폴더의 업로드 자료에 포함하지 않았다. 오류 예시도 싣지 않았다.
